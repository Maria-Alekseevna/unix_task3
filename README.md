# Задача 3: MyInit — упрощённый аналог init

## Что делает программа

`myinit` — это демон, который запускает и отслеживает дочерние процессы по конфигурационному файлу, автоматически перезапуская их в случае завершения.

## Основной функционал

1. **Демонизация**
   - Смена рабочего каталога на корневой (`/`)
   - Закрытие всех файловых дескрипторов
   - Отключение от управляющего терминала
   - Логирование в `/tmp/myinit.log`

2. **Работа с конфигурационным файлом**
   - Формат строки: `путь_к_программе_с_ключами файл_stdin файл_stdout`
   - Проверка абсолютных путей (начинаются с `/`)
   - Перенаправление stdin/stdout дочерних процессов

3. **Слежение за процессами**
   - При завершении любого дочернего процесса — автоматический перезапуск
   - В лог пишется причина завершения и факт перезапуска

4. **Обработка сигнала SIGHUP**
   - Перезагрузка конфигурационного файла
   - Завершение всех текущих процессов
   - Запуск новых процессов по обновлённому конфигу

## Ключевые системные вызовы

- fork() — создание дочерних процессов
- execvp() — запуск программ в дочерних процессах
- waitpid() — отслеживание завершения процессов
- sigaction() — обработка сигналов (SIGHUP)
- kill() — отправка сигналов процессам

## Тестирование (`runme.sh`)

Скрипт выполняет три проверки:

| Тест | Действие | Ожидаемый результат |
|------|----------|---------------------|
| 1 | Запуск myinit с конфигом на 3 процесса | 3 дочерних процесса |
| 2 | Убийство 2-го процесса (`pkill`) | Процесс перезапущен, снова 3 процесса |
| 3 | Замена конфига на 1 процесс и отправка SIGHUP | Остался 1 процесс, в логе все события |
